### Visual style (common DNA)
- **2D flat vector illustration**, real 3D nahi. "3D feel" aata hai **2.5D parallax** se: foreground (characters), midground (temple/pillars), background (sky/stars) alag layers mein dheere move karte hain.
- **Camera**: slow push-in (Ken Burns), zoom on face/object for emphasis, whip-transitions between scenes.
- **Lighting FX**: diya/sun ka **soft radial glow**, **light rays (god rays)**, **floating bokeh/dust particles** (har frame mein), vignette (edges dark).
- **Colour palette**: Temple = deep brown/maroon + gold glow; Divine = blue/purple night sky; Revelation = orange-gold sunburst.
- **Backgrounds**: temple garbhagriha with pillars + toran, starry night, simple gradient with particles for "concept" shots (e.g. only कपूर on a plate).

### Text / Graphics
- **Kinetic captions** top par: word-by-word reveal, key word **yellow/gold** highlight.
- **Keyword cards**: bada Devanagari word (gold calligraphic serif — "दर्शन", "कपूर", "अहंकार") ya **red ribbon tag** ("क्यों?", "घड़ी की", "मुख तक").
- **Label tags**: chhoti underlined labels ("पहला रहस्य", "दीप", "गर्भगृह").
- **Shlok cards**: Sanskrit + transliteration (Kar Darshan, Hanuman).
- Numbering: बड़ा "3" with three diyas — "teen rahasya" visual promise.

### Hook strategy (first 3 sec)
1. **Question about a ritual everyone does** but nobody knows why (Aarti, Kar Darshan) — sabse strong.
2. **Myth-busting claim** ("Hanuman never used Gada… before you start abusing me").
3. **Relatable modern habit vs ancestors** (mobile vs haath).
4. **First-person divine POV** ("मैं शनि हूँ").
- Hook ke turant baad **open loop**: "इसके पीछे छिपे हैं 3 सुंदर रहस्य" → viewer end tak rukta hai.

### Script structure (winning formula)
`Hook (question) → Promise (3 rahasya) → Context (Sanskrit word / shastra reference) → Rahasya 1 → 2 → 3 (har ek ka 1 keyword card) → Emotional/life lesson → Comment CTA ya Part-2 cliffhanger`
- Pace: ~2.5–3 words/sec, short sentences, "..." pauses before reveal.
- Authority: "परंपरा कहती है", "श्रीमद्भागवत में…", "वाल्मीकि रामायण में…".
- Ending: viewer se kuch **likhwana** (भजन / हर हर महादेव / ॐ नमः शिवाय) = comments boost.

### Audio
- Reference narrators (pitch measure kiya): 95–125 Hz — mostly **deep/heavy male**. Aapne deep nahi maanga, isliye sab samples isse halki/clear aawaaz mein hain.
- Soft devotional BG (bansuri/santoor/temple bells), whoosh on transitions, "ding"/shimmer on keyword reveal.

Kyun ye topic: Aarti-thali / Kar Darshan jaisa **"ritual ka rahasya"** format (aapke references mein sabse strong), Shiv content (ref 6) + har mandir jaane wala ise karta hai, par reason nahi jaanta.
